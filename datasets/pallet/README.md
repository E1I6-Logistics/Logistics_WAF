# 팔레트 학습 영상 수집

원본은 `raw/<세션명>/`에 저장하며 `.gitignore`의 `/datasets/pallet/raw/` 규칙으로
Git에서 제외한다. 라벨링 전 데이터이며 학습/검증 분할이나 자동 정답 생성은 하지 않는다.

## 수집 명령 — 개발 PC

```bash
source /opt/ros/jazzy/setup.bash
ROS_DOMAIN_ID=11 PYTHONPATH=/usr/lib/python3/dist-packages:$PYTHONPATH \
  /usr/bin/python3 /home/sojeong/turtlebot3_ws/scripts/collect_pallet_dataset.py \
  --seconds 60 \
  --output /home/sojeong/turtlebot3_ws/datasets/pallet/raw/새로운_세션명
```

출력 폴더는 새 이름이어야 한다. ROS JPEG와 CameraInfo만 구독하며 로봇 제어
명령은 발행하지 않는다. 기본 60초, 최대 1800프레임/200MiB JPEG까지만 저장한다.
영상이 15초간 처음부터 오지 않거나 수집 중 5초간 끊기면 종료한다.
2초 이상 오래되거나 1초 넘게 미래인 이미지 시각은 거부하므로 장비 시간이 맞아야 한다.
관찰용 AVI 추가 용량은 JPEG 용량 제한에 포함되지 않는다.

| 파일 | 내용 |
| --- | --- |
| `frames/*.jpg` | 수신 JPEG 바이트 그대로, 재압축/왜곡 보정 없음 |
| `frames.jsonl` | 이미지 시각, 수신 시각, 크기, CameraInfo 참조, 밝기/선명도/변화량 |
| `camera_info_*.json` | 실제 수신한 K/D/R/P와 영상 크기·프레임·ROI 정보 |
| `preview.avi` | 관찰용 MJPEG 영상, 평균 수신 FPS로 재생 |
| `summary.json` | 수집 종료 원인, 개수, FPS, 보정 정보 대응 개수 |
| `assessment.json` | 사람이 확인한 시야/학습 적합성 평가(있는 세션만) |

AVI는 프레임별 불규칙 간격을 표현하지 못하므로 시간 분석은 JSONL을 사용한다.
CameraInfo가 아직 도착하지 않았거나 프레임/크기가 다르면 해당 JPEG의
`camera_info_id`는 null이다. 실제 수신하지 않은 대응 관계를 임의로 채우지 않는다.
프레임 변화량과 선명도는 참고값이며 자동 라벨/불량 판정값이 아니다.

## 5장에 대한 8점 시험 라벨링

`curated/20261028_label_trial_01/`에 네 번째 촬영분의 서로 다른 배치 5장을 골라
팔레트 박스와 입구 모서리 총 40개 점의 시각적 초안을 작성했다.

원본은 유지하고 `images/draft/`에 복사했으며 `labels/draft/`에 YOLO Pose 형식으로 저장했다.

순서는 왼쪽 입구 좌상→우상→우하→좌하, 오른쪽 입구도 동일하다.
입구 전면을 기준으로 하며 뒤쪽 경계나 그림자의 윤곽이 아니다.
`annotations.json`에 픽셀 좌표와 점별 주관적 검토 반경(2~4px)을 기록했다.
이 반경은 측정된 오차가 아니며 visibility=2도 위치 정확도를 보장하지 않는다.
결과는 미검증 초안으로, 사람이 검수한 확정 정답이나 모델 성능 검증 결과가 아니다.

`review_contact_sheet.jpg`, `overlays/*_zoom.png`에서 점 번호와 검토 원을 볼 수 있다.
형식 29개 필드, 좌표 정규화/역변환, 박스 내부/사각형 순서와 이미지 복사본을 검사했다.
raw 전체 5,820개 파일의 작업 전후 SHA-256도 일치했다.
설치·권한 변경·외부 업로드·학습/검증 분할·모델 학습·로봇 이동은 하지 않았다.
